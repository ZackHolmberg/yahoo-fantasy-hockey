## What that implies
- Hits and blocks are worth a lot: 150 blocks = 112 pts, the same as about 19 goals. Physical defensemen are gold.
- Centers get about +50 to +120 from faceoffs, so centers are plentiful and the C replacement level is high (~425 FP vs ~305 for wingers).
- Goalies: a save is +0.6 and a goal against is -3, so each shot faced at a .900 save percentage is worth about +0.24. Workload is king; an average starter scores ~8 FP per start.
- Only one G slot per day, so a 2nd goalie only counts on days your #1 isn't playing. The live tracker discounts the 2nd and 3rd goalie (x0.5, x0.2).
